# sdd-study

Spec-Driven Development（SDD）的学习笔记和实验。

- `sdd_decision_points.md`：SDD 流程里需要人做判断的节点。
- `superpowers_sdd_plan_report.md`：读 [obra/superpowers](https://github.com/obra/superpowers) 的 SDD 计划流程后的报告。
- `sdd-pack/`：一套可以放进仓库的 SDD 文档与校验模板（`lean/`、`standard/` 两档），`scripts/verify.cjs` 按 `.sdd/validation.json` 跑检查并写 receipt。
- `my-spec/`：练习写的需求规格。
