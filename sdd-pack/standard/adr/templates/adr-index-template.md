# ADR Index

This file is the entry index for ADRs. For architecture or design decisions, read this file first, then open specific ADRs only when needed.

## Status Legend

- Proposed: not yet accepted; still open for discussion or revision.
- Accepted: currently effective decision.
- Rejected: explicitly not adopted.
- Superseded: historical decision replaced by a later ADR.

## Maintenance Rules

- Update this file whenever an ADR is created, rejected, accepted, or superseded.
- `ADR` must match the ADR filename.
- `File` must link to the concrete ADR.
- `Decision` is a one-sentence summary, not copied ADR body.
- `Status` must match the concrete ADR file.
- When a new ADR supersedes an old ADR, update `Supersedes` and `Superseded by` on both affected rows.
