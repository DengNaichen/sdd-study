# ADR Index

此文件是 ADR 的入口索引。处理架构或设计决策时，先读本文件，再按需读取具体 ADR。

## 决策列表

| ADR | 日期 | 状态 | 决策 | 置信度 | 文件 | 替代 | 被替代 | 相关资料 |
|---|---|---|---|---|---|---|---|---|
| ADR-XXXX | YYYY-MM-DD | 提议中 | <一句话说明决策结果> | 高 / 中 / 低 | [ADR-XXXX-title.md](ADR-XXXX-title.md) | - | - | requirement / plan / issue / PR |

## 状态说明

- 提议中：尚未最终接受，可以讨论或修改。
- 已接受：当前有效决策。
- 已拒绝：明确不采用的决策记录。
- 已被替代：历史决策，已被后续 ADR 替代。

## 维护规则

- 每新增、拒绝、接受或替代一份 ADR，都必须更新本文件。
- `ADR` 编号必须和文件名一致。
- `文件` 必须链接到具体 ADR。
- `决策` 只写一句话摘要，不复制 ADR 正文。
- `状态` 必须和具体 ADR 文件一致。
- 新 ADR 替代旧 ADR 时，同时更新两行的 `替代` / `被替代` 字段。
