Standard SDD Artifact Flow

Pure skill workflow: requirement → plan/research → ADR → tasks → implementation → debt.

Requirement requirement.md
长期需求事实、用户故事、验收标准。
Plan plan.md
技术设计、文件结构、测试策略。
Research research.md
仅在存在真实不确定性时生成。
ADR docs/adr/
只沉淀长期关键决策。
Tasks tasks.md
Files、Interfaces、TDD 微步骤、Review Gate。
Implement / Debt 按任务验证落地；已接受遗留进入 docs/debt/。

Artifact Rules

Artifact Policy Purpose
requirement.md Required Authoritative behavior and acceptance source.
plan.md Required Design strategy, technical context, file mapping, test strategy.
research.md Optional Evidence for uncertain decisions, choices, constraints, and risks.
docs/adr/ Optional Durable decisions that future maintainers will need explained.
tasks.md Required Executable task tree organized by user story and phase.
docs/debt/ Optional Accepted non-blocking follow-up work after implementation.

这是展示材料，不是 skill 运行时文件。集成到支持 skill 的仓库时，只需要复制 standard/。
