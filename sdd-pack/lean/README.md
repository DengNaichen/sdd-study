# Lean Workflow

Lean files are retained as reference material. The supported integration target is the pure skill in `standard/`.

## Commands Included

| Command | Output | Description |
|---|---|---|
| `speckit.specify` | `requirement.md` | Create a compact Requirement from a feature description |
| `speckit.plan` | `plan.md` | Create a compact implementation plan from the Requirement |
| `speckit.tasks` | `tasks.md` | Create dependency-ordered checklist tasks from Requirement and plan |
